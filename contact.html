Frequently Asked Questions

Are WePDFHub tools really free? ▼

Yes! All core PDF tools on WePDFHub are completely free to use. No hidden fees, no watermarks, and no credit card required. Simply upload your file and process it instantly.

Are my uploaded files safe and private? ▼

Absolutely. All uploaded files are processed securely over HTTPS and are automatically and permanently deleted from our servers within 1 hour of processing. We never read, store, or share your file contents.

Do I need to create an account to use the tools? ▼

No signup is required for basic tool usage. You can use most tools directly without creating an account. Creating an account gives you access to additional features like file history.

What file size is supported? ▼

We support PDF files up to 50MB for free users. If you need to process larger files, please contact us and we'll try to assist you.

How can I request a new PDF tool? ▼

We love hearing from users! Use the contact form above, select "Feature Request" as the subject, and tell us which tool you'd like us to add.
